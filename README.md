# Social Media Analytics using SQL

## Project Overview

This project focuses on analyzing social media platform data using SQL and GenAI-assisted query generation.

The project uses a `Social_Media` database containing users, posts, comments, likes, followers, hashtags, and post-hashtag relationships.

## Database Tables

The database contains 7 tables:

* users
* posts
* comments
* likes
* followers
* hashtags
* post_hashtags

The dataset contains approximately 7,000 synthetic records.

## Analysis Performed

The project covers the following analyses:

1. Most Active Users
2. Most Liked Posts and Creators
3. Top Countries by Average Engagement
4. Trending Hashtags
5. Top Influencers
6. Followers Who Never Interacted
7. Hashtags with Highest Engagement
8. Busiest Posting Hours
9. Inactive Users
10. Top Countries with Most Influencers

## SQL Concepts Used

* ORDER BY
* LIMIT

* COUNT()

* AVG()

* Self-joins
* Date and time functions

## GenAI Usage

GenAI was used to assist with SQL query generation, understanding SQL requirements, explaining JOINs and aggregate functions, resolving errors, and verifying query logic.

## Key Business Insights

* Active users contribute significantly to platform engagement.
* Some posts receive higher levels of engagement than others.
* Popular hashtags can improve content visibility and engagement.
* Posting activity varies across different hours.
* Inactive users can be identified for potential re-engagement.
* Country-level influencer analysis can support marketing strategies.
